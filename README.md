# homebrew-tap

David Awad's personal Homebrew tap.

## Usage

```bash
brew install davidawad/tap/docdiff
```

Or explicitly:

```bash
brew tap davidawad/tap
brew install docdiff
```

## Formulae

| Name      | Description                                                          |
| --------- | -------------------------------------------------------------------- |
| `docdiff` | Git-diff style plaintext compare for Word and other legal documents. |
